# Shopping Cart

A simple shopping cart application built with HTML, CSS, and JavaScript. Users can add products with prices, remove products from the cart, and calculate the total price of all items.

## Features

- Add products to the shopping cart
- Assign prices to products
- Remove products from the cart
- Check whether a product exists before removing it
- Display all products currently in the cart
- Calculate and display the total cart price
- Handle an empty shopping cart
