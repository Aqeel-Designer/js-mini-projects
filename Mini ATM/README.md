# Mini ATM

A simple ATM simulation built with HTML, CSS, and JavaScript. The application allows users to deposit and withdraw money while displaying the updated account balance.

## Features

- Display initial account balance
- Deposit money
- Withdraw money
- Check available balance before withdrawal
- Display updated balance and transaction messages
- Prevent withdrawals when the amount exceeds the available balance

## Technologies

- HTML5
- CSS3
- JavaScript

## Concepts Used

- DOM Manipulation
- Variables
- Functions
- Event Handling
- Conditional Statements
- Number Conversion
- Template Literals
- Updating HTML Content
