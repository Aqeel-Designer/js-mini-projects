# Stopwatch

A simple stopwatch built with HTML, CSS, and JavaScript. It allows users to start, stop, and reset a timer that displays elapsed time in hours, minutes, seconds, and milliseconds.

## Features

- Start the stopwatch
- Stop and pause the timer
- Resume from the previously elapsed time
- Reset the stopwatch to zero
- Display hours, minutes, seconds, and milliseconds
- Update the display at short intervals

## Technologies

- HTML5
- CSS3
- JavaScript
