# Weather App

A weather application built with HTML, CSS, and JavaScript that uses the OpenWeather API to retrieve and display current weather information for a selected city.

## Features

- Search for weather information by city name
- Fetch current weather data from the OpenWeather API
- Display city name, temperature, humidity, and weather description
- Display weather-related emojis
- Change the background video based on the current weather condition
- Handle invalid or unavailable city names
- Handle empty city input
- Dynamically create and display weather information
- Display error messages when weather data cannot be retrieved
