# Digital Clock

A simple digital clock built with HTML, CSS, and JavaScript. It displays the current time in a 12-hour format and updates automatically every second.

## Features

- Display the current time
- Show hours, minutes, and seconds
- Use the 12-hour time format with AM/PM
- Update the clock automatically every second
- Add leading zeros to single-digit time values

## Technologies

- HTML5
- CSS3
- JavaScript

## Concepts Used

- DOM Manipulation
- Functions
- `Date` Object
- `getHours()`
- `getMinutes()`
- `getSeconds()`
- `setInterval()`
- `toString()`
- `padStart()`
- Ternary Operator
- Modulus Operator
- Template Literals
- Updating HTML Content
