# Calculator

A simple calculator built with HTML, CSS, and JavaScript. It performs basic arithmetic operations while displaying the complete calculation expression and handling common input errors.

## Features

- Perform addition, subtraction, multiplication, and division
- Display the complete calculation expression
- Prevent multiple decimal points
- Automatically add `0` when a decimal is entered first
- Replace an operator when another operator is selected
- Prevent division by zero
- Handle incomplete calculations
- Clear the calculator and reset its state
- Start a new calculation after displaying a result
