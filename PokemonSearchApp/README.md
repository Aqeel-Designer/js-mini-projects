# Pokémon Fetch API

A simple Pokémon search application built with HTML, CSS, and JavaScript. Users can enter a Pokémon name and retrieve information from the PokéAPI, including its name, type, and sprite image.

## Features

- Search for a Pokémon by name
- Fetch Pokémon data from the PokéAPI
- Display the Pokémon's name
- Display the Pokémon's type
- Display the Pokémon's sprite
- Handle empty search input
- Handle Pokémon not found errors
- Clear previous results when a new search fails

- PokéAPI
