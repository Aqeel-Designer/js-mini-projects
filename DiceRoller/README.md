# Dice Roller

A simple dice roller built with HTML, CSS, and JavaScript. Users can choose the number of dice to roll and the application generates random dice values along with their corresponding images.

## Features

- Choose the number of dice to roll
- Generate random dice values
- Display the rolled values
- Display an image for each rolled dice
- Support rolling multiple dice at once

## Technologies

- HTML5
- CSS3
- JavaScript
