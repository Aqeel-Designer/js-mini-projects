# Temperature Converter

A simple temperature conversion tool built with HTML, CSS, and JavaScript. Users can enter a temperature and convert it between Celsius and Fahrenheit.

## Features

- Convert Celsius to Fahrenheit
- Convert Fahrenheit to Celsius
- Display the converted temperature
- Round the result to one decimal place
- Validate that a conversion unit has been selected

## Technologies

- HTML5
- CSS3
- JavaScript

## Concepts Used

- DOM Manipulation
- Variables
- Functions
- Event Handling
- Conditional Statements
- Number Conversion
- Radio Buttons
- Mathematical Operations
- `toFixed()`
- Updating HTML Content
