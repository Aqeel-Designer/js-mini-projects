# Password Generator

A simple password generator built with HTML, CSS, and JavaScript. It generates a random password using lowercase letters, uppercase letters, numbers, and symbols.

## Features

- Generate a random password
- Generate a 12-character password
- Include lowercase and uppercase letters
- Include numbers and symbols
- Combine different character types in one password

## Technologies

- HTML5
- CSS3
- JavaScript

## Concepts Used

- DOM Manipulation
- Variables and Constants
- Functions
- Conditional Statements
- Ternary Operator
- `Math.random()`
- `Math.floor()`
- Loops
- String Concatenation
- String Indexing
- Template Literals
